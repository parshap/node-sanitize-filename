# Security

If you find a vulnerability that's exploitable in realistic use, for example
attacker-controlled input producing a filename that escapes its directory,
please report it privately using GitHub's
[Report a vulnerability](https://github.com/parshap/node-sanitize-filename/security/advisories/new)
form. This includes denial of service with input sizes an application could
realistically accept; include the input size and timing.

Bugs without a realistic security impact, including Windows naming edge cases
and minor performance issues, are welcome as regular issues or pull requests.

Fixes are released for the latest 1.x version only.
